Use the Linear MCP tools (`save_issue`, `list_issues`, `get_issue`, `save_comment`, `sub_issue_write`) — not `gh`, not markdown files. Team `S-a-c` is required on issue create.

## Workflow conventions

- **Milestones**: Linear milestones (0.1.x–0.5.x) mirror the Roadmap document; attach every issue to the milestone it belongs to.
- **Wayfinder**: map issues are labelled `wayfinder:map`; their tickets are child issues labelled `wayfinder:<research|prototype|grilling|task>`; blocking uses native `blockedBy` relations. One ticket per session; claim by assigning first; resolve by comment → close → append the gist to the map's Decisions so far.
- **Triage**: the five canonical labels exist as Linear workspace labels — see `triage-labels.md`.
- **Project-management docs** live in the project's Linear documents (Vision & Goals, Roadmap, Conventions & Integration); `ROADMAP.md` in the repo mirrors the Roadmap document.
